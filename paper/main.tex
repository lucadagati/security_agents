\begin{abstract}
Security evaluations of autonomous AI agents are typically performed in
isolation: a single agent is probed with a fixed attack, or a defender is
scored against a static adversary. We argue that this view is incomplete.
When attackers and defenders are themselves learning agents that interact
repeatedly, each side observes the other, adapts, and may invent strategies
that no evaluation script encoded. Security then becomes a co-evolutionary
process. This paper introduces a framework for studying that process in a
controlled cyber environment. Agents are defined by capabilities, goals,
memory and a policy, under partial observability; strategy is
\emph{not} hard-coded. We distinguish three adaptation levels---static,
episodic, and persistent cross-episode learning---and define two metrics
aimed at co-evolution: co-evolutionary pressure (CEP) and emergent security
risk (ESR). A seedable simulator and an optional Kubernetes cyber range
share the same interface, so populations from one to twenty agents can be
studied reproducibly. On a one-versus-one adaptation ladder, moving from
static to adaptive attackers reduced the detection rate from $0.975$ to
$0.55$ and raised attack success, while persistent co-evolution was
classified as an arms race and produced behaviours (strategic patience,
delayed attack, deception) that were absent from agent objectives. The
result supports the central claim: risks that cannot be observed in
isolated-agent evaluations emerge once attackers and defenders adapt to
one another.
\end{abstract}
