\section{Co-Evolutionary Agent Security Framework}
\label{sec:framework}

\subsection{Architecture}
The system has three layers, shown in Fig.~\ref{fig:architecture}:
(i)~an agent population of attackers and defenders;
(ii)~a cyber environment that exposes hosts, services, credentials,
logs and vulnerabilities;
(iii)~an evaluation layer that records trajectories and computes
metrics. An experiment controller drives the loop of
Fig.~\ref{fig:loop}.

\subsection{Decision Loop}
At each turn an agent receives a partial observation, consults memory,
and selects a single structured tool. The environment validates
parameters against a JSON schema, applies the action, and returns a
result. The LLM, when used, never executes code; it only names a
capability~\cite{schick2023toolformer,yao2023react}. Heuristic policies
implement the same interface, which lets the co-evolutionary machinery
be validated without a language model and later swapped for an Ollama
backend on local GPUs.

\subsection{Memory}
Null memory realises L0. A sliding window of in-episode actions realises
L1. L2 additionally stores a one-line reflection distilled from the
episode outcome (success, detection, false positives). The reflection
is the only cross-episode channel: we do not fine-tune weights between
episodes. This is closer to how deployed LLM agents will actually
``learn'' from operations---by writing notes---than to classical
reinforcement learning~\cite{shinn2023reflexion}.

\subsection{Co-Evolutionary Loop}
Fig.~\ref{fig:loop} and the following procedure implement the
controller. Each episode produces experience that can change future
behaviour. The scientific object is the trajectory of policies
$\pi^{(t)}\mapsto\pi^{(t+1)}$, not a single success rate.

\subsection{Strategy Signature}
To measure change we need a numeric fingerprint of $\pi_i$. We use a
mixed signature $s_i\in\mathbb{R}^k$ comprising (a)~an explicit
strategic parameter (stealth for attackers, vigilance for defenders)
and (b)~the empirical distribution of tool categories over a recent
window. Distance between signatures is Euclidean on the union of keys.
This is crude by design: it is computable online and does not require a
learned behaviour embedding.
