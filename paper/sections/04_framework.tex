\section{Co-Evolutionary Agent Security Framework}
\label{sec:framework}

Fig.~\ref{fig:architecture} shows the three-layer architecture: agent
populations, cyber environment, and evaluation/analytics connected by an
experiment controller. The controller implements the co-evolutionary loop
of Fig.~\ref{fig:loop}. The scientific object is the trajectory of policies
$\pi^{(t)}\mapsto\pi^{(t+1)}$, not a single scalar score.

\input{figures/architecture}

\paragraph{Decision loop.}
At each turn an agent receives a partial observation, reads memory, and
selects one structured tool. The environment validates parameters against
a JSON schema, applies the action, updates suspicion and compromise state,
and returns a result. Language models propose tool names and parameters from
a fixed schema~\cite{schick2023toolformer,yao2023react}; heuristic policies
implement the identical interface so the measurement apparatus can be
validated on transparent policies first (Section~\ref{sec:method-policies}).

\paragraph{Memory and adaptation.}
Null memory realises L0; an in-episode sliding window realises L1; L2 adds
a compact cross-episode reflection~\cite{shinn2023reflexion}. Adaptation is
behavioural and log-inspectable: no weight fine-tuning between episodes.
Policy classes, memory semantics, hybrid gates and heuristic parameter updates
are specified in Section~\ref{sec:method-policies}.

\paragraph{Measurement hooks.}
Each step emits a trajectory record (observation, action, outcome,
rationale, strategy label, memory update). Episode-level signatures feed
CEP, dynamics classification and emergence tagging
(Section~\ref{sec:method-analysis}). Optional coalition graphs aggregate
same-role communication when enabled in E3--E8.
