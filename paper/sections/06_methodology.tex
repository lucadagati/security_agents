\section{Experimental Methodology}
\label{sec:method}

This section specifies what we measure, how policies adapt, and how the
two empirical studies are executed. Section~\ref{sec:results} reports
outcomes only; all protocol choices are defined here.

\subsection{Experimental design}
\label{sec:method-design}

(Section~\ref{sec:environment}): a heuristic adaptation ladder and a
language-model campaign. Within each study only the factors in

The ladder crosses attacker and defender adaptation levels in nine
one-versus-one cells: a $2{\times}2$ L0/L1 block (static/static through
adaptive/adaptive), an L2/L2 anchor (persistent/persistent), and four
asymmetric L2 crossings that isolate which side drives detection and CEP.
We begin at $1$A+$1$D because population studies confound adaptation with
communication and role specialisation. The extended E1--E8 matrix
(supplementary material) scales the same instrumentation to larger
populations in future work.

\subsection{Policy classes and adaptation}
\label{sec:method-policies}

\textbf{Heuristic policies} implement the same tool interface as LLM
agents. Tunable parameters are attacker \emph{stealth} $s\in[0,1]$ and
defender \emph{vigilance} $v\in[0,1]$. Within an episode, stealth governs
cooldown after noisy actions ($\text{cooldown}=\mathrm{round}(2s)$ idle turns
via \texttt{wait}) and rises by $+0.25$ when a decoy is triggered; vigilance
lowers the suspicion threshold ($1.2-v$) and increases monitoring probability.

Cross-episode updates apply only under L2 (persistent). For the attacker,
if an episode ends with detection and failure, $s\leftarrow\min(1,s+0.15)$; if
success without detection, $s\leftarrow\max(0,s-0.05)$; if timeout without
detection, $s\leftarrow\max(0,s-0.10)$. For the defender, if the attacker
succeeds, $v\leftarrow\min(1,v+0.15)$; otherwise $v\leftarrow\max(0.1,v-0.03)$.
Under L1, $s$ and $v$ reset to base values each episode but within-episode
adaptation (cooldown, vigilance spikes on new alerts) still occurs.

\textbf{Memory levels} follow Section~\ref{sec:problem}: L0 fixes policy
and memory; L1 keeps an in-episode action window cleared at each reset; L2
retains a one-line cross-episode reflection (text for LLM agents, reflection
plus parameter carry-over for heuristics). No weight fine-tuning occurs
between episodes.

\textbf{Hybrid LLM policies} address stall and illegal proposals on our
arena. The model receives legal capability hints derived from the current
observation (progress toward the data store, not a fixed script) and proposes
one schema-valid tool per turn; common parameter errors are autorepaired from
the observation. The heuristic gate takes over when (i) the proposed tool is
not among the legal hints, (ii) the LLM is stuck for two consecutive turns
(repeated reconnaissance, invalid harvest, or repaired actions), or (iii) the
attacker has not reached a service foothold after six LLM steps (three steps
without credentials on shallow probes). Gate steps are logged separately so
ASR/DR attribute joint model-and-gate behaviour conservatively. Pure LLM
ablations disable the gate and are interpreted directionally only.

Baselines B1/B2 are rule-based L0 agents; B3--B5 are LLM or hybrid agents at
L0, L1 and L2 respectively.

\paragraph{Language-model protocol.}
Primary LLM cells use Ollama with \texttt{qwen2.5:14b} for both roles
(B3--B5, phase~1). Supplementary scale ablations swap in
\texttt{llama3.1:8b} or \texttt{qwen3-coder:30b} on hybrid B5 only
(phase~3). Each turn the model receives a JSON schema for one tool call,
the partial observation, in-episode memory (L1/L2) and legal capability
hints derived from the observation. Prompts are assembled in
\texttt{HybridPolicy}/\texttt{LLMPolicy} (\texttt{policy.py}); no chain-of-thought
is elicited. Token budget is capped at 512 per decision; invalid JSON or
schema violations trigger at most one parameter repair from the observation
before the hybrid gate may take over.

Each run logs \texttt{hybrid\_gate\_stats} in the aggregate JSON:
fraction of LLM vs.\ heuristic steps, gate interventions (illegal tool,
stall, or lack of foothold progress), and repair count.
\input{figures/generated/gate_stats}
We attribute ASR/DR jointly to model and gate and do not re-run LLM cells
without the gate for primary claims.

\emph{legal capability hints} (schema-valid next steps derivable from the

\paragraph{LLM memory and L2 reflections.}
Language-model agents condition on \texttt{memory.context()} prepended to the
observation. Under L1 (B4), only the last eight in-episode actions appear
(e.g.\ \emph{Recent actions this episode: t4 recon $\to$ ok; \dots}); the
block is cleared at each reset, so cross-episode learning in B4 must come from
in-episode reflection and hybrid gate behaviour within an episode, not from
retained text across episodes. Under L2
(B5), \emph{PersistentMemory} appends a one-line reflection after every episode
using deterministic outcome templates, for example \emph{Detected and failed; be
stealthier and pace actions} (attacker, detected failure) or \emph{Held the line;
keep monitoring the service and data layers} (defender, clean episode). Up to
twelve reflections are injected as \emph{Lessons from previous episodes} on
subsequent prompts. B4 episodic runs therefore adapt mainly within an episode;
B5 runs accumulate generic outcome summaries that often repeat without changing
tool choice, which aligns with the persistent-memory underperformance in
Table~\ref{tab:llm} (H4).

\subsection{Metrics and hypotheses}
\label{sec:method-metrics}

Let $\mathcal{E}_T$ be episodes in a run. Primary outcome metrics are
\begin{align}
  \mathrm{ASR}
  &=
  \frac{\bigl|\{\,e : \text{exfiltration succeeded}\,\}\bigr|}
       {\bigl|\{\,e : \text{attack attempted}\,\}\bigr|},
  \label{eq:asr}\\[2pt]
  \mathrm{DR}
  &=
  \frac{\bigl|\{\,e : \text{at least one detection}\,\}\bigr|}
       {\bigl|\{\,e : \text{attack attempted}\,\}\bigr|}.
  \label{eq:dr}
\end{align}
Timeouts and illegal actions remain in the denominator so stall behaviour is
visible. Process metrics include co-evolutionary pressure
\begin{equation}
  \mathrm{CEP}
  \;=\;
  \frac{1}{T-1}
  \sum_{t=1}^{T-1}
  \frac{\bigl\|s_A^{(t+1)}-s_A^{(t)}\bigr\|_2
        +\bigl\|s_D^{(t+1)}-s_D^{(t)}\bigr\|_2}{2},
  \label{eq:cep}
\end{equation}
where $s_i^{(t)}$ merges a strategic scalar (stealth or vigilance) with
normalised counts $cat_k$ of tool categories over the last sixteen actions
within the episode. To remove same-seed ambient turnover in action mix, we
also report baseline-adjusted pressure on paired seeds:
\begin{equation}
  \mathrm{CEP}_{\mathrm{adj}} \;=\; \mathrm{CEP} - \mathrm{CEP}_{\mathrm{S/S}},
  \label{eq:cep-adj}
\end{equation}
where $\mathrm{CEP}_{\mathrm{S/S}}$ is the static/static cell on the \emph{same}
random seed. Positive $\mathrm{CEP}_{\mathrm{adj}}$ indicates excess strategy
turnover beyond the L0/L0 control, not proof of adversarial co-adaptation alone.
Emergent security risk
\begin{equation}
  \mathrm{ESR}
  \;=\;
  \frac{P(\mathrm{failure}\mid \mathrm{interaction})}
       {P(\mathrm{failure}\mid \mathrm{isolation})}
  \label{eq:esr}
\end{equation}
requires paired isolation runs and is deferred (H3). Table~\ref{tab:hyp}
lists hypotheses and their status; H1--H2 are tested on the ladder,
H4 and H7 on hybrid LLM cells, H3 and H6 on future population work. H5 is
\emph{not tested}: stealth pacing and delayed attack are encoded in
$B_A^{\mathrm{enc}}$ for ladder runs (Table~\ref{tab:encoded}).

\subsection{Analysis pipeline}
\label{sec:method-analysis}

Data are collected at three levels: step trajectories, episode records and
run aggregates (Table~\ref{tab:episode-record}). After each run:

\begin{enumerate}
\item \textbf{Signatures and CEP.} Population signatures $s_A^{(t)}$,
  $s_D^{(t)}$ are computed per episode; CEP is Eq.~\eqref{eq:cep}.
\item \textbf{Dynamics class.} We compute $\bar{\delta}_{\mathrm{early}}$ and
  $\bar{\delta}_{\mathrm{late}}$ on \emph{parameter} distances (stealth and
  vigilance only) and on full signatures. Primary labels use parameters
  (Table~\ref{tab:dynamics}); full-signature labels are reported descriptively
  because action-mix features fluctuate stochastically even under L0. Thresholds:
  stable if $\bar{\delta}_{\mathrm{late}}<0.02$; non-convergent if
  $\bar{\delta}_{\mathrm{late}}\ge 0.6\,\bar{\delta}_{\mathrm{early}}$; else
  converging.
\item \textbf{Emergence tagging (exploratory).} Each role declares an encoded set
  $B_i^{\mathrm{enc}}$ (Table~\ref{tab:encoded}). For every step in the
  trajectory log, the analysis engine maps the executed tool to a tool
  category, then to one or more behaviour tags via the taxonomy in
  Table~\ref{tab:taxonomy}. Tags observed but absent from $B_i^{\mathrm{enc}}$
  enter \texttt{candidate\_emergent}. We report candidates descriptively only;
  primary claims do not rely on H5 because pacing tags are encoded for the ladder.
\end{enumerate}

Table~\ref{tab:taxonomy} lists the post-hoc taxonomy (offensive, defensive and
social labels). None of these tags are objectives; they are inferred from
action categories after the fact.

\subsection{Statistical protocol}
\label{sec:method-stats}

Primary ladder and B3--B5 cells use six seeds
($\{100,110,\ldots,150\}$ for the ladder). We report seed-level means with
95\% Student-$t$ confidence intervals and seed-paired $t$-tests with Cohen's
$d$ and mean paired differences (Table~\ref{tab:stats-tests}; script
\texttt{scripts/paper\_analysis.py}). Comparisons are exploratory without
multiplicity correction. Figures and Tables~\ref{tab:ladder}--\ref{tab:cep-adj}
are regenerated from \texttt{runs/ci/ladder\_ci.json} and
\texttt{runs/campaign/final\_report.json} via
\texttt{scripts/generate\_paper\_figures.py}.
