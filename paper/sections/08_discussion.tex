\section{Discussion}
\label{sec:discussion}

If the one-versus-one ladder generalises beyond the present sandbox,
isolated-agent evaluations will understate operational risk: a deployment
that passed a static red team can remain unsafe once the adversary retains
memory of prior detections. Certification should specify the adaptation
level of both sides. The language-model results add that deploying a
capable model is neither a red team nor a defence; outcomes depend on
tool constraints, memory regime and hybrid control structure. Unexpected
tool sequences should be interpreted through strategy signatures (CEP,
novelty), not automatically as new vulnerability classes.

Equation~\eqref{eq:security-fn} treats security as a function of
interaction and history. The heuristic ladder shows that view under
transparent policies; the hybrid LLM cells show that the same
instrumentation applies when decisions are model-generated, provided the
agent completes the offensive chain often enough for adaptation to be
observable. Negative results (static hybrid, persistent hybrid, larger
coder model) delimit when co-evolutionary measurement is possible.

The simulator's detection physics, coarse partial observability, and
toy-network topology limit external validity. Hybrid policies improve
measurability but attribute success jointly to model and heuristic gate.
The Kubernetes backend has not yet been evaluated on a provisioned range.
Population experiments may reverse qualitative conclusions once
communication is enabled; ESR requires paired isolation runs not yet
executed. Primary cells use six seeds with confidence intervals;
supplementary ablations use fewer seeds and should be read as directional.
ASR and DR do not capture partial compromise. Nevertheless, if
co-evolution and adaptation-regime effects do not appear in this minimal
setting, they are unlikely to be identifiable in noisier ranges without
stronger instrumentation.
