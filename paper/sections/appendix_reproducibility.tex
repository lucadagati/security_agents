\section{Artifact and Reproducibility}
\label{app:repro}

The experimental platform supporting this study is publicly available at
\begin{center}
\url{https://github.com/lucadagati/security_agents}
\end{center}
The repository contains the \texttt{coevsec} implementation, declarative
experiment configurations, the analysis pipeline, unit tests, and
instructions for reproducing the heuristic ladder and language-model
baselines reported in Section~\ref{sec:results}. Each run is keyed by
configuration, seed and repository revision; trajectories and aggregated
metrics are written automatically. Language-model experiments require a
local or remote Ollama endpoint; heuristic experiments run fully offline.
Further detail on setup, dependencies and the optional Kubernetes backend
is maintained in the repository documentation rather than duplicated here.
